# Индекс проектов: визуальное направление

Креативный директор, 10 окт 2026. Смотрел исходники `new-test-ru` (`css/main.css`, `src/pages/work.html`, `src/partials/experience.html`, `src/index.html`) и /ru/work/ на 1440, 820 и 375.

## 1. Где живёт

**Индекс ставим отдельной секцией на /work/, сразу под сеткой кейсов:** `(02) Index` / `(02) Все проекты`, якорь `#index`, в обоих файлах (`src/pages/work.html`, `src/ru/pages/work.html`). Отдельная страница не нужна: шесть кейсов и полный список на одной странице и дают ощущение объёма. Сетка показывает глубину, индекс показывает широту.

На главной таблицу не копируем. В конце абзаца `(05) Клиенты` ставим одну ссылку в существующем паттерне `.more > .more__link`: «Все проекты (24) →» / «All projects (24) →» на `/ru/work/#index`. Блок «Опыт» (`experience.html`) не трогаем: он про роли, а индекс про проекты. Если дублировать, обе вещи станут слабее.

## 2. Структура

**Колонки, слева направо:** Год · Проект · Сфера · Работа · →.
Сортировка от новых к старым. Внутри года сначала идёт более поздний проект, а не кейс.

**Год пишем только там, где он меняется.** В остальных строках года той же группы ячейка пустая (для скринридера год остаётся в `.visually-hidden`). Так получаются группы без заголовков групп и без лишних линеек.

**Строка с кейсом:** `<a class="row idx__row">`, справа `.row__c` со стрелкой → (уже есть в `a.row .row__c::after`). При наведении стрелка сдвигается на 4px, Сфера и Работа становятся `--fg` (так уже работает `.row__b`). **Текстовая строка:** `<div class="idx__row">`, без стрелки и без hover. Название в обоих случаях `--fg`. Различие только в стрелке и интерактивности, вторую гарнитуру или жирность не добавляем. NDA-проекты называем по сфере («CRM для клиники»), без пометки «NDA». Собственные концепты помечаем словом «Концепт» в `--mute` после названия (`.idx__tag`). **Источник (Contra, Kwork, напрямую) на сайт не выводим:** храним в данных (`data-source`), клиенту он ничего не говорит.

**Шапка:** в `.block__head` номер `(02)`, заголовок и `.count` справа: `(24)`. Под ней строка подписей колонок `.idx__head`: Год / Проект / Сфера / Работа (EN: Year / Project / Sector / Scope), 13px, `--mute`.

**Фильтр: не делаем.** 15–30 строк читаются за полтора экрана, а фильтр превращает список в интерфейс. Единственная альтернатива, если строк станет больше 40: текстовые переключатели в той же строке, что и `.idx__head`, справа. «Все · Сайты · Интерфейсы · Айдентика», 13px, активный пункт `--fg`, без пилюль.

**Ширины.** Колонку «Сфера» ставим ровно на левый край второй карточки сетки выше (у `.work--all` две колонки с зазором 20px), то есть на `50% + 10px`:

## 3. Типографика и классы

Переиспользуем `.block`, `.block__head`, `.count`, `.row`, `.row__c` (стрелка), `.visually-hidden`, `.more__link`. **Класс `.rows` на список не вешаем:** его анимация (`.motion-ok .rows > *`) по очереди прорисовывает линейки с шагом 80ms. На 24 строках это 2 секунды каскада, то есть ровно тот построчный fade-in, который Артём отверг. Линейки у индекса статичные. Секция может появиться целиком, как остальные `.block`.

```css
.idx li { border-top: 1px solid var(--line); }
.idx li:last-child { border-bottom: 1px solid var(--line); }
.idx__head, .idx__row { display: grid; column-gap: 20px; align-items: baseline;
  grid-template-columns: 5.5rem calc(50% - 10px - 5.5rem - 20px) minmax(0,1fr) minmax(0,1fr) 1.25em; }
.idx__head { padding-bottom: 10px; font-size: 13px; color: var(--mute); letter-spacing: 0; }
.idx__row { padding-block: 12px 14px; }
.idx__year { color: var(--mute); font-variant-numeric: tabular-nums; }
.idx__name { font-size: var(--t-head); line-height: 1.2; letter-spacing: -0.035em; } /* как .exp__org */
.idx__tag  { margin-left: 0.5em; font-size: var(--t-base); letter-spacing: 0; color: var(--mute); }
.idx__sector, .idx__what { color: var(--mute); }  /* --t-base, на одной базовой линии с названием */
a.idx__row .row__c { justify-self: end; }
```

Все колонки, кроме названия, набраны в `--t-base`. Название набрано в `--t-head` и сидит с ними на общей базовой линии (`align-items: baseline`), поэтому разный кегль читается как иерархия, а не как разнобой. Одна гарнитура, вес 500, два серых, волосяные линии.

820: `grid-template-columns: 4.5rem minmax(0,1fr) minmax(0,0.8fr) 1em`, `.idx__sector` переносим в `grid-column: 2; grid-row: 2` с `padding-top: 2px`.
375: `grid-template-columns: minmax(0,1fr) auto; row-gap: 2px`. Название слева, год справа (в каждой строке, стрелка после года), вторая строка `Работа · Сфера` в `--mute`. `.idx__name` 17px, `.idx__head` `display: none`.

## 4. Что делает его сделанным, а не таблицей

1. **Год только при смене.** Левая колонка становится ритмом: 2026 … пусто … 2025. Вертикальная структура появляется без заголовков и лишних линий. Это самый дешёвый и самый заметный признак набранного вручную списка.
2. **Скрытая сетка с карточками.** Колонка «Сфера» начинается ровно там, где вторая карточка кейсов выше, а «Год» стоит по левому краю первой. При прокрутке от сетки к списку глаз продолжает ту же вертикаль, и индекс читается как продолжение страницы, а не как вставленная таблица.

Без картинок за курсором, без построчных появлений, без подсвеченных цифр.
