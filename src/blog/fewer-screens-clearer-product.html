The brief asked for a new dashboard. What the product needed was fewer places to look. We ended the redesign with fewer screens than we started with, and support questions dropped.

Start with What People Open

Analytics told a simple story: most people opened the same three views, every day, in the same order. Everything else was visited during onboarding and then forgotten. The navigation treated all of it as equal.

Merge Before You Redesign

Two of the three daily views showed the same data from different angles. Combining them into one screen with a single switch removed a step from the most common task. No new visual style would have done as much.

  • Settings that were changed once moved behind one entry.
  • Reports became a filter on the main view, not a separate section.
  • Empty states explained what would appear there, instead of showing zeros.

Then Make It Calm

Only after the structure was simpler did we work on the surface: one type size for data, one for labels, colour only for state. A product people use for hours a day should feel quiet.
