(06)Questions

(05)
Framer or code — which will my site be built in?

Whichever fits the project. When you want to edit the site yourselves, I build it in Framer: you change text and images in the browser and add content through its CMS. When the site needs more than Framer gives, I build it in code, as I built this one.

Can we update the site ourselves after launch?

Yes. In Framer you change text and images in the browser and add blog posts, case studies or other repeating content through its CMS — without touching code or the layout. I set the CMS up around the content you’ll actually change.

We already have a website. Do we have to start over?

Not necessarily. If the site mostly works, I can start by reviewing its usability, structure, technical SEO and performance, give you a prioritised list of changes and make them myself. If it needs replacing, the redesign starts from the brand and content you already have.

We only need the design, or only the build.

That works too. Web DesignWeb Design gives you layouts ready to build, and Website Development builds a design you already have.

How does a project start?

With a short message: what you’re building, whether there’s a site already, when you’d like to start and a rough budget — the project form asks just that. I come back with questions or a quote. Once we agree the scope, the price is fixed.
